# Suggested Commands

## Development
```bash
npm run dev          # Start Next.js dev server (http://localhost:3000)
```

## Backend (PocketBase)
```bash
cd db
./pocketbase serve   # Start PocketBase at http://127.0.0.1:8090
# Admin UI: http://127.0.0.1:8090/_/
```

## Build & Production
```bash
npm run build        # Build Next.js for production
npm run start        # Start production server
```

## Linting
```bash
npm run lint         # Run ESLint (next lint, extends next/core-web-vitals)
```

## Dependencies
```bash
npm install          # Install all dependencies
```

## System Utilities (Darwin/macOS)
```bash
ls, find, grep, cat, git   # Standard Unix tools available via zsh
```
